#### ⚡ AURA | Personal Routine & Growth PWA Tracker

<div align="center">
  <a href="https://github.com/abhishekh002/routine-tracker">
    <img src="https://github-readme-stats-eight-theta.vercel.app/api/pin/?username=abhishekh002&repo=routine-tracker&bg_color=000000&border_color=00f2fe&title_color=00f2fe&text_color=e2e8f0&icon_color=00c6ff" width="450" />
  </a>
</div>

A zero-framework, 100% offline-compliant Progressive Web App (PWA) designed to track college routines, 2-hour DSA blocks, speech-to-text English practice, and mindfulness meditation.

| Layer | Technology Stack |
|---|---|
| **Frontend** | Vanilla JS (ES6+), HTML5, Glassmorphism CSS3 |
| **PWA Engine** | Service Worker, Web App Manifest, Stale-While-Revalidate |
| **APIs** | Web Speech, Web Audio (136.1Hz Synth), Web Share API |
| **CI/CD** | GitHub Actions → GitHub Pages |

🔗 [Live PWA App](https://abhishekh002.github.io/routine-tracker/) &nbsp;•&nbsp; [Source Code](https://github.com/abhishekh002/routine-tracker)
